# ✨ PromptCraft

Turn your ideas into better AI prompts.

PromptCraft is a simple, beginner-friendly web application that helps users create structured AI prompts for learning, programming, writing, research, and business.

🚀 Features

- Multiple prompt categories
- Custom task descriptions
- Different response styles
- Instant prompt generation
- Copy-to-clipboard functionality
- Responsive, dark-themed interface

🛠️ Built With

- HTML5
- CSS3
- JavaScript

🎯 Mission

Make AI easier to use by helping everyone communicate their ideas more clearly and effectively.

📌 Current Status

Early-stage project. More features and improvements are planned.

🔮 Future Improvements

- More prompt templates
- Prompt history
- Custom prompt settings
- Improved mobile experience
- AI API integration
